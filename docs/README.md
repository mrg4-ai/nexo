# Documentación de Nexo Local V1.1

Este directorio describe el proyecto implementado, incluida la landing, el perfil local, onboarding, ayuda y demo aislada de V1.1. No contiene funcionalidades hipotéticas.

- [Manual de usuario](manual-usuario.md): uso cotidiano, conceptos y protección de datos.
- [Arquitectura](arquitectura.md): capas, flujo de datos y principios local-first.
- [Estructura del proyecto](estructura-proyecto.md): carpetas y archivos relevantes.
- [Modelo de datos](modelo-datos.md): entidades TypeScript, relaciones y campos derivados.
- [Lógica financiera](logica-financiera.md): fórmulas reales y tratamiento de ceros.
- [Almacenamiento local](almacenamiento-local.md): claves, validación, migración y fallos.
- [Backup y exportación](backup-y-exportacion.md): JSON, importación atómica y CSV.
- [PWA y offline](pwa-offline.md): manifest, Service Worker, cachés y actualización.
- [Guía de desarrollo](desarrollo.md): instalación, comandos y extensión segura.
- [Testing](testing.md): cobertura automatizada y comandos.
- [Checklist de release](release-checklist.md): controles para cada publicación.
- [Checklist de dispositivos](pwa-device-checklist.md): pruebas manuales pendientes.
- [Solución de problemas](solucion-problemas.md): recuperación y diagnóstico seguro.
- [Limitaciones de V1](limitaciones-v1.md): alcance deliberado de la versión local.
- [Evolución futura](evolucion-futura.md): nota arquitectónica breve, sin implementación.
